# Asset provenance

- `images/weather/*.webp`: newly generated for Solaris Atmosphere Scanner using the built-in OpenAI image-generation tool. These are AI-generated illustrative scenes, not sourced photographs, live observations, or location-identifying views. No third-party photographer attribution is represented. No exclusive copyright or trademark clearance is asserted.
- `images/weather/weather-fallback.svg`: original simple vector background created for this project.
- `branding/solaris-mark*.svg` and favicon/app-icon derivatives: original vector solar-ring design created for this project. The mark is not a trademark-clearance opinion.
- `branding/solaris-wordmark-*.svg`: original layout with Cormorant Garamond and Inter glyph outlines; font licenses included.
- `fonts/cormorant-garamond-*.woff2`: Google Fonts Cormorant Garamond regular 400, medium 500 and semibold 600, downloaded as TTF from fonts.gstatic.com and losslessly repackaged to WOFF2. See `cormorant-garamond-ofl.txt`.
- `fonts/inter-*.woff2`: Google Fonts Inter regular 400, medium 500, semibold 600 and bold 700, downloaded as TTF from fonts.gstatic.com and losslessly repackaged to WOFF2. See `inter-ofl.txt`.
- `icons/weather/*.svg` and `icons/ui/*.svg`: Lucide SVG geometry, rendered with project stroke width/colors. Upstream names and exact installed version are in `../icons/icon-sources.json`. Preserve `lucide-isc.txt` when distributing.

Sources: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond ; https://github.com/google/fonts/tree/main/ofl/inter ; https://lucide.dev/

Hero art direction: photorealistic wide 16:9 generic atmosphere, low horizon, quiet darker left side for copy, detail and natural illumination toward right, navy/ivory/amber Solaris palette. Separate clear, partly cloudy, overcast, rain, thunderstorm, snow and fog day/night scenes. Snow uses an open snow plain; other scenes use a generic water horizon. No city landmarks, text, branding or UI embedded in the backgrounds. All scenes are static; no additional animation assets are required.
